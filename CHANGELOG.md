# Changelog

## 0.1.0 — 2026-10-18

- Restore the historical ADL GT2 revision-0 CCS eligibility restriction.
- Reject compressed Iris modifiers and shared ISL modifier overrides on affected silicon.
- Add stepping/device controls and real surface-allocation regression checks.
- Correct 64-bit DRM modifier parsing on 32-bit builds without relaxing tests.
- Document bounded rendering, PCSX2, streaming, native host and Steam results.
- Package source-first build recipes, probes, Chinese/English findings and recovery guidance.

This initial publication ships no binary driver release and does not claim to
repair all ES, kernel/firmware, video-acceleration or PCIe problems.
